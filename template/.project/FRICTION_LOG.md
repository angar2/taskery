# FRICTION_LOG

> 짜증 / 한계 / 짚이는 부분 누적.
> 메인이 사용자 발화에서 *"이거 짜증나"* 감지하거나 사용자 명시 요청 시 한 줄씩 추가.
> `/refine` 슬래시가 정독 + 반복 패턴 감지 + bottoms-up 보강 제안.

**사용 규칙**:
- 한 행에 한 짜증
- 손수 편집 X — 메인이 대화로 적음
- *"이거 짜증나, 적어줘"* 발화 또는 메인 자체 감지 시 추가
