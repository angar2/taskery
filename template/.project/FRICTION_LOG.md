# FRICTION_LOG

> 사용자가 작업 흐름 중 겪은 불편 / 한계 / 짚이는 부분의 누적.
> `/log-friction` 스킬이 사용자 합의 후 한 행씩 추가한다.

**사용 규칙**:
- 한 행에 한 불편
- 손수 편집 X — 메인이 대화로 적음
- 사용자 명시 호출 / 사용자 불만 발화 캐치 / task-close 직후 마찰 신호 자체 감지 시 추가
