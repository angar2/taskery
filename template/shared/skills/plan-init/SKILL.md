# plan-init

새 기능 묶음(플랜)을 더하는 단계다.

- 새 기능 묶음을 추가할 때 쓴다. 받은 기획 문서가 있으면 읽고, 없으면 핵심만 묻는다.
- `plan-init <slug>`(제목은 `--title`) 명령으로 플랜 번호·폴더·`PLAN.md` 틀을 만든다.
- `PLAN.md`에 목표와 태스크 목록을 적는다. 항목 한 줄 형식은 `<항목 번호>. <한 줄 설명> — 선행: <항목 번호들 또는 없음>`이다(명령이 이 형식을 읽고, 열린 태스크 번호를 줄 끝에 붙인다). 다른 태스크가 먼저 끝나야 하는 태스크는 선행 태스크 칸에 적는다. 같은 파일을 크게 만지는 태스크끼리도 순서를 두는 편이 낫다.
- 이 기획이 바꾸는 제품 문서(`spec/`)만 고친다.
- 만든 것과 태스크 목록을 보고한다.

## 부르는 명령

- `plan-init`
