# MOCKUP_RULE

> 화면 목업의 위치와 형식이다. 사용자가 목업을 요청했을 때만 만들고, 그때 읽는다.

## 위치

- 태스크 문서 옆 `mockup/` 폴더에 `<태스크 문서 이름>-mockup.html`로 둔다. 예: `.taskery/plans/001_mvp/tasks/mockup/012_settings-save-mockup.html`. 폴더는 처음 쓸 때 만든다.
- 태스크 하나에 목업 파일 하나다. 화면이 여럿이면 한 파일 안에서 절로 나눈다.

## 형식

- 정적 HTML 한 파일이다. 스타일은 파일 안 `<style>`, 움직임이 필요하면 파일 안 `<script>`로 쓰고 외부 라이브러리를 쓰지 않는다.
- 레이아웃·색·간격·글꼴처럼 화면에서 보이는 것을 담는다. 클릭·호버는 흉내만 내도 된다.
