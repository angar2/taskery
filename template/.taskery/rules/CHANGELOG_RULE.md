# CHANGELOG_RULE

> 변경 기록의 형식이다. `close-task`가 끝난 태스크를 닫을 때 아래 "항목 틀"을 읽어 한 항목을 쓴다.

## 위치

- `.taskery/changelog/<YYYY-MM>.md` — 달마다 한 파일. 없으면 명령이 만든다.
- 최신 항목이 맨 위에 온다.

## 항목 틀

명령은 아래 코드 블록을 읽어 `{num}`(세 자리 번호)·`{title}`(태스크 제목)·`{date}`(닫은 날)·`{type}`(유형)·`{goal}`(`## 목표` 첫 줄)을 채운다. 틀을 고치면 다음 항목부터 그 모양으로 적힌다.

```markdown
## [TASK-{num}] {title}

- 날짜: {date}
- 유형: {type}
- 요약: {goal}
```

## 쓰는 때

- 끝난 태스크(병합했거나, 병합이 필요 없는 태스크의 마무리를 마친 태스크)만 적는다. 포기로 닫은 태스크는 적지 않는다.
- 적힌 항목은 사람이나 AI가 보강해도 된다.
